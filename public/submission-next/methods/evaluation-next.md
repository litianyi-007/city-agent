## 开始前冻结的内容

每项真实实验先写入 plan.json，记录：代码 commit及工作树差异 hash；任务/问卷/人口包/画像清单 hash；完整 Prompt与版本；Provider、Base URL、Model ID；Harness及分析版本；所有实验臂与其唯一变化；画像 seed；输出Token、超时、并发和调用总上限；预算币种、单价来源及计价规则；缓存及重试规则；核心题、指标、分母、诊断目标和停止线。

供应商不支持 temperature 或推理 seed 时记录“未设置/不支持”，不通过 SDK 未支持参数假装冻结。模型 selector 不等于独立认证底层权重。基准并发1、答卷缓存关闭、每画像独立新会话、自动重试0；若后续允许一次修复调用，必须另立配置版本，分别报告首次完整率、最终完整率和额外费用。

任何 Prompt、模型、题目、Gate 或采样变化都开启新实验版本。发现评分器缺陷时，保留旧评分并以新评分版本对同一原始答卷重新计算；不能更改原始答卷来通过门限。开发夹具与本地HTTP伪供应商属于工程验证，不计真实质量结果。

## S03 完整性和工程停止线

第一步使用10个预登记唯一画像做冒烟，覆盖可行街道、年龄档、性别和实际选择的人群预设。10/10完整有效是扩大实验的路径目标；不足则停止扩容，保存原因，在新版本修复后重新登记冒烟。完整并不表示人口代表性，也不认定人设偏好合理。

第二步另冻结30个画像的完整 cohort，目标至少29/30完整有效，即96.67%达到原协议≥95%的整数门限。分母固定为全部30个计划画像：未启动、取消、拒答、截断、超时、格式错误和已声明硬矛盾均不从分母删除；一次失败后新实验重跑不能抹去原失败。

当前 live API 上限为12人。30人计划需要受预算控制的调度支持，或把同一冻结30人清单按不超过12人的子批执行，保存 cohortId、原始画像ID、子批运行ID映射。此能力未验收前不能直接发30人请求。三次同seed、同10人生成不构成30人验证；分段不得重复抽样或静默把新的画像代替未完成画像。

离线报告至少包含：

| 指标 | 分母与含义 |
| --- | --- |
| planned、started、not-started、failed、invalid、valid | 画像层级，彼此定义明确；planned永不按成功数缩小 |
| structureComplete / planned | 全部必答题结构完整的画像；不同于仅能解析JSON |
| validComplete / planned | 结构完整且全部已声明画像硬约束通过；未声明的语义不自动算通过 |
| firstAttemptComplete / planned | 如将来允许返修，首次表现仍单列 |
| 每题应答/缺答/无效及分组 planned/valid | 不适用仅按预冻结规则处理；多选分母不能用选择次数代替答卷数 |
| uniqueProfiles、duplicateProfiles、覆盖单元 | 合成身份与人口单元覆盖；重复画像不算独立真人 |
| 模型调用、缓存、重试、Token、耗时和费用 | adapter调用与实际供应商请求/账单分开；未知usage或价格为null/unknown |

人口边际复算、确定性统计、秘密隔离、取消和预算停止是硬门限，必须通过。画像覆盖均衡由抽样策略产生，不是恢复真实联合分布的证据。对样本比例可以报告合成样本分布，但不附“滨江市场置信区间”。

## S04 自洽盲评

预先冻结评分表，覆盖全部30个计划画像及其答卷，不只挑有完整开放题的成功样本。已有年龄/街道声明式约束由代码复算；职业、家庭、购买角色及开放题按以下类别分别登记：

1. 明确逻辑矛盾：例如画像明确18岁却选择60岁以上；回答“从未使用AI”又在同一问卷无条件陈述日常使用AI，且没有尝试/时间变化等解释。
2. 信息缺失或不可判定：没有足够条件、语句含混、格式失败或完全未启动。不可判定不是通过，也不是自动认定逻辑矛盾。
3. 可理解的偏好张力：高隐私关注仍愿试用、经济约束下偶尔买较贵商品等，不依据人口刻板印象判失败。
4. 未登记的画像事实：回答中的职业、家庭和资格只能标生成情景，不升级人口事实。没有明确画像约束的职业不能被评分器认证为真实。

盲评输入保留任务、画像和原答卷，但隐藏模型名称、实验臂、此前分数及最终结论；顺序由冻结seed打乱。至少两位独立评审者按同一表评分，保存各自原始标签、分歧和裁决。评审者可以是人工或额外授权模型，但必须注明类型；模型共识不作为事实真值，模型评审也计入独立调用账本。

报告每类 planned、可评、不可评、矛盾、张力、分歧及未决数量。初始工程诊断目标是：30人基准的已声明硬画像矛盾为0；语义逻辑矛盾不超过全部计划画像的10%，且每一项有可复核证据。不可评比例超过10%时语义诊断为inconclusive，不能按剩余少量可评答卷宣称通过。此门限是Demo预登记目标，不是通用科学合格线；失败后不临时调宽。

## S04 重测和条件实验

从30人 cohort 用冻结seed选择6个画像，尽量覆盖三街道与可行年龄/性别组合，明示不能覆盖全部单元。下列实验先做小规模预算估计，经授权逐项开展；不默认执行全因子组合。

| 实验 | 初始计划调用数 | 冻结与主要指标 |
| --- | --- | --- |
| 五次新会话重测 | 6×5＝30 | 固定完整画像、问卷、模型与Prompt；冻结核心单选题，缺答/失败为null，最大一致数按5次计划计；每画像≥4/5为诊断目标，初始总体目标至少5/6画像达到 |
| 独立19/29元价格对照 | 6×2＝12 | 只改同规格标准版价格，所有报价出现处同步；两臂都删除问卷内条件追问，避免混入两个价格情景；报告逐画像转移、有效配对数、完整计划分母及负方向 |
| 独立权益对照 | 6×2＝12 | 价格、容量、购买资格不变，只改一项明确权益；不同画像分开报告，不把年龄/家庭差异归成权益因果 |
| 等义措辞 | 6×2＝12 | 含义与选项ID不变，由盲审确认无新增承诺；报告核心选项改变数、缺答和开放题变化 |
| 选项顺序 | 6×2＝12 | 仅排列顺序改变，选项ID/文本和画像规则不变；不允许重新编号造成答案映射假变动 |
| 完整画像/仅人口/无画像 | 6×3＝18 | 同问卷与预算，记录输入暴露范围；结构完整率可比，自洽只评价各臂实际可见约束 |

上述完整组合共96次居民调用；加S03的10＋30，初始预留最多136次，不含规划、语义评审、其他未见任务或新增版本。这个调用上限不是付费授权，也不是费用估算；审批可以仅批准一项、降低样本，或不运行。所有启动过的实验仍进账本。

价格提高后模拟购买选择不必机械下降，权益变化也不保证人人选择增加。若出现反方向，保留并检查解释、无效和任务冲突；不能靠Prompt要求单调来“证明”敏感性。措辞/顺序初始目标为每项至少5/6核心选择保持一致；失败、缺答不算一致。两臂配对分析另报可用分母，不把6画像探索写成总体显著性或真实因果。

无画像臂无法知道被隐藏的年龄/街道，不能因与隐含画像不一致就判它语义质量失败。把该项标not-applicable，同时报告旧执行器按完整画像规则作出的原始标签，解释两者区别；不得改原记录来隐藏差异。不同暴露产生不同结果只说明条件敏感，不证明完整画像更真实。

## 简单非LLM基线

内部诊断增加两个独立、标为fixture的基线：固定“不确定/不适用”策略（仅存在相应选项时适用）和seeded随机合法选项策略。只在有明确映射的题目上比较结构完整、核心选项分布和稳定性；不可把随机数值或虚构开放题当“居民”。基线的确定性稳定由算法保证，不是居民真实性优势。

有外部数据后，再用训练集的总体众数/均值、预登记分组经验频率或上期观测作为简单预测基线。训练和留出严格分离；不在留出集选基线、调Prompt、增画像或选最容易预测的题。没有现实参考时，不宣布LLM或哪种消融条件胜出。

## S13 现实留出校准

启动条件是具有明确授权、可去标识且可审计的真实资料，并明确目标、地区、时期、单位、资格与覆盖范围。学校场景分开儿童本人偏好、监护人许可/预算和试售成交；宠物场景分开购买者、宠物类别、零食/主粮及SKU规格。订单猫狗比例只代表该业务已观测客户，除非具备目标人群抽样设计，不能外推滨江居民养宠比例。

在建模前按用户/家庭/订单主体分组冻结留出，防止同一主体跨训练与测试；涉及未来运营时用时间留出并记录时效。留出不得进入画像、Prompt、参数或阈值选择。数据量、授权与目标尚未确定前，不提前宣称具有统计功效或“达到95%准确率”。

主要指标依任务预登记：分类选择的预测与观测分布差异、概率校准（只有模型真的输出预登记概率时才算）、支付意向与实际支付的差别，以及整体和有效分组误差。与同口径简单基线比较，另列目标资格缺失、非响应、覆盖偏差、不可观测组及时间差。最小组样本门限在看留出结果前确定；不足组不合并成虚假的高精度结论。

初始通过条件不是固定漂亮百分比，而是：来源/授权/分母/留出隔离完整，原始结果可重算，指标与基线公平且负结果保留。具体业务可接受误差须由实际使用者事先明确；未达时只交付研究预演，不支持真实选址、库存或利润承诺。

## 本批离线评分工具

`shared/research-evaluation.ts`导出严格的completenessPlanSchema、createCompletenessPlan和evaluateCompleteness。计划显式冻结任务/人口/画像/系统Prompt、模型selector/版本/参数hash、完整居民ID、阈值、曝光范围及声明注册时间。原始运行先经parseSurveyEvidence复算Prompt、答卷、统计、五层预设血缘与调用/Token/费用账本；未知费用不能填零。

```bash
npx tsx scripts/evaluate-completeness.ts plan.json survey-run.json new-evaluation-report.json
```

命令不访问网络，不调用模型，不覆盖已有报告或原输入。计划必须在真实执行前生成并由独立记录保存；工具中的时间与live模式仍来自声明，不能认证不可伪造预登记或供应商实际付费。输出registrationIdentity/executionIdentity明确未独立认证；threshold-met只是冻结范围内门限，外部有效性仍not-validated。fixture永不通过realThirtyResidentGate，消融组不冒充完整画像真实30人基准。
