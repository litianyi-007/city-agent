# 可追溯虚拟居民：五层画像与滨江适配方法

版本与联网核对日期：2026-10-07。来源登记：persona-source-register.json（源码相对路径：`../../data/research/persona-source-register.json`；需源码包）。这是新增研究依据，不修改已冻结的申报 PDF、附件或人口包；它不宣称已获得滨江真人访谈、人格常模、联合微观人口或消费偏好。

## 1. 五层是信息组织方法，不是人格因果公式

建议保留五条可独立修改的轴，以人口、地域和统计时点为共同锚点。不要把“遗传 → 成长 → 教育 → 家庭 → 职业”做成确定性的生成流水线。人口学背景不等于人格，画像丰富不等于真实。

| 层 / 当前字段 | 可设置内容 | 事实、假设和未知如何区分 | 禁止的推断 |
| --- | --- | --- | --- |
| 人格 `personality` | 开放性、尽责性、外向性、宜人性、情绪稳定性及明确描述的自定义倾向 | 当前 0–100 只是用户仿真刻度；未设置用 `null`，不默认 50。没有真人适用量表及核验，不称实测、百分位或诊断 | 学历高所以开放性高；收入高所以尽责；性别、户籍、父母职业决定人格；DNA 标签 |
| 成长 `upbringing` | 成长期间主要照护结构、迁居、寄宿、城乡经历 | 真实经历需合法获得的独立来源；当前预设均是情景假设。当前家庭不能反填童年经历 | 祖辈照护、单一照护或乡村经历自动产生某人格/购买行为 |
| 教育 `education` | 学习阶段、受教育程度、在读/结业/获学位等应分别描述 | 官方边际只能约束原表分类；在读状态及细分学历未核验则未知 | “小学文化程度”=当前小学生；本科/研究生人数=已获学位人数；研究生自动拆成硕士/博士 |
| 家庭 `household` | 当前关系、同住结构、照护职责、购买/许可决策角色 | 家庭户总量是背景事实；成员结构、养宠、儿童年龄和决策权需另外补采 | 平均 2.39 人/户=三口之家；已婚=有小学子女；独居=养猫；照护必须同住 |
| 工作与经济 `work` | 就业状态、职业、社会角色；金额区间附币种、周期和个人/家庭、税前/可支配口径 | 当前 UI 仅提供个人税前月收入或家庭月可支配收入的假设；区级年度人均统计不可直接写入 | 地区产业增加值比例=居民职业比例；人均可支配收入=个人工资/家庭收入；收入=零食预算 |

当前 `residentPersonaSchema` 把整个五层对象固定标为 `provenance: assumption`；上述“来源事实”保留在独立证据登记，不因选择预设而成为居民事实。五层能解释情景差异，不能替代目标资格（家长、在校生、宠物购买者）、分母或抽样权重。已有预设只是探索不同生活背景的组合，不是滨江真实人群类别或占比模型。

## 2. 人格框架的科学与许可边界

[Soto / John 原作者 BFI 页面](https://www.ocf.berkeley.edu/~johnlab/bfi.html)介绍 BFI-2 五维与 15 个细分面向，引用 2017 原始研究；作者保留版权，非商业研究可使用，商业用途需联系授权，且无官方已发表常模手册。当前没有复制题项、实施量表或使用美国常模。UI 的“情绪稳定性”与负性情绪/神经质方向相反，只是概念方向说明，不是可换算的 BFI-2 分数。

[Lee / Ashton 原作者 HEXACO 页面](https://hexaco.org/hexaco-inventory)提供六维量表；[维度说明](https://hexaco.org/scaledescriptions)含诚实—谦逊。它不是在 Big Five 上简单增加一项，情绪性与宜人性的组织也不同。免费条件限非营利学术研究，公开在线量表及非学术使用有额外限制。本版不混合量表分数、不复制其问卷。若后续需要可再用题项，[Goldberg / ORI 的 IPIP](https://www.ipip.ori.org/)为公共领域备选；公共领域不等于中文、儿童或滨江适用性已经验证。

[Vukasović / Bratko 2015 原始元分析摘要](https://pubmed.ncbi.nlm.nih.gov/25961374/)报告人格差异的平均遗传估计约 0.40，且双生子与家庭/收养设计估计不同。这是研究人群中差异的估计，不是“一个人 40% 基因、60% 环境”，更不是 agent 的混合系数或从 DNA/家庭标签预测个体的工具。此项目不采集、生成或猜测遗传信息；成长经历作为独立背景，而非人格计算器。

## 4. 从新区域到可审计样本：两本账

第一本是**人口校准账**：冻结区域/边界版本、年份、常住或户籍、年龄覆盖及原表分类 → 留存原件和定位 → 校验单位/分母/总数/重复引用 → 记录可识别的联合表及缺失项 → 再合成样本。现版仍按街道内年龄与性别独立进行逻辑分层（`infer`），不是五层画像联合采样。详见 [人口方法](population-methodology.md)。

以后引入 IPF 前，必须取得同范围同期间的边际、部分联合表或适用种子，检查总数相容、结构性零与覆盖缺口。种子、独立性、分类 crosswalk 都是显式假设；发布边际误差、未约束组合和替代种子的敏感性。边际拟合得好不识别真实相关性，不能凭它证明生活背景或偏好。[Ye 等 2017 人口合成原始研究](https://www.jasss.org/20/4/16.html)可作为方法依据；**本版没有实现 IPF 或五层总体联合拟合**。

第二本是**情景覆盖账**：为研究问题挑选不同生活/决策情景，保留为何纳入、资格是否假设、每层未知项、模型及 seed。这是有目的的压力测试，不是概率抽样。没有在校生家庭/养宠家庭的合格总体分母，就不赋予该情景“滨江占比”，不以人口权重修补资格缺失，不生成真实总体置信区间。每个输出保留人口证据 `fact`、联合推断 `infer`、画像 `assumption` 和作答 `generated` 的不同来源，模型不得用生成答案反证画像真实。

## 5. 虚拟受访者的依据与反证

[Park 等 2023 Generative Agents](https://arxiv.org/abs/2304.03442v2)在 25 个 agent 的 Sims 风格环境中研究观察、记忆、反思和计划，提供架构启发，不证明人口或商品研究有效。记忆、dream 与 MCP 外部现实绑定仍是后续目标，本批画像/观测契约不算已实现这些能力。

原“Generative Agent Simulations of 1,000 People”已更新。锁定 [Park 等 arXiv v3，2026-06-28](https://arxiv.org/abs/2411.10109v3)：1,052 名美国参与者，访谈、结构化自报或结合；留出 GSS 问题表现分别为参与者自身两周重测一致性的 83%、82%、86%，纯人口学背景为 74%。这些是特定评估的**相对基准**，不是本项目准确率、绝对准确率或滨江商品偏好验证。

[Argyle 等 2023 silicon sampling](https://doi.org/10.1017/pan.2023.2)支持在特定美国调查、模型与条件信息下比较合成回答和真人回答的方法，不保证跨文化/商品通用有效。[Bisbee 等 2024 反证研究](https://doi.org/10.1017/pan.2024.5)显示均值相似仍可能压缩差异、失真相关关系，并随提示或时间改变。应优先用本地合法聚合调查/自报与试售做外部验证；仅有合成结果时交付假设和补采计划。

## 6. 自证问卷与后续验收

小学零食题：先明确向家长/监护人问购买与许可，学生使用体验是另一个问题；区级在校生不能直接当家长分母。问近期实际购买、频次、可接受规格和渠道，允许“不了解孩子偏好”“未购买”“不适用”，不能在画像中先写“喜欢低糖零食”再把同一答案当调研发现。真实儿童研究须独立伦理与授权审查，本版不开展无监护儿童招募。

宠物题：先区分目标是宠物零食还是主粮；猫粮/狗粮信息不能自动回答猫/狗零食主营方向。问具体宠物种类、近期实际零食购买及规格、成交价格、购买渠道，保留“不养宠”“仅购主粮”“没有零食消费”“不知道”，价格统一净含量/用途后再比。旧客订单仅代表覆盖客户，不代表区域全部养宠者。

建议下阶段验收不是“所有居民会答、答案不变”：记录模型/版本、完整 Prompt、参数、样本框/画像版本和来源 ID；测试小幅措辞、题序、seed 及异构模型改变后的组间差异/未知率/排名稳定性；检查注入结论和刻板印象；在独立真人/交易留出集上验证目标指标。先报告差异与失败，再根据真实业务风险预注册可接受门限，不借用论文数值充当本地门限。

当前可以展示有追溯链的情景研究流程；缺资格分母、经营/地理或真实消费证据时必须 `needs-data`。方法文档及来源登记不是新的统计人口包，不会自动激活数据或发布商业推荐。
