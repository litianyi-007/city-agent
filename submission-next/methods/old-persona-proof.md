五层与统计框独立，全部标 `provenance: assumption`，未知字段保留null、unknown或空列表，不能通过年龄/性别/街道自动补齐：

| 人格倾向 | 0–100情景Big Five分数与自定义说明；未设置为null，不是人格量表测量或DNA | personality-context；不能直接推导品类、价位、意愿 |

## 在自己电脑复现

使用本分支干净源码及项目Node22环境完成 `npm ci`。下面脚本无需Key，不启动服务，不下载浏览器，不调用Harness或外部API：

```bash
npx tsx scripts/create-persona-proof.ts
```

输出目录每次使用新UUID，使用exclusive写入，不覆盖旧报告或 `public/submission/`。也可做30人规则覆盖和不同seed：

```bash
npx tsx scripts/create-persona-proof.ts --count=30 --seed=42
```

30/30夹具完整也不算EV-10真实完整率通过。脚本拒绝live参数和凭证；要做真实模型验证，需在独立本机页面重新配置实际Model ID与Key，并按 [下一批评测预登记](evaluation-next.md) 另获预算、冻结配置、保存新实验。

