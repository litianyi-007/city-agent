# 可追溯人口建模方法：从区域到证据包

版本：2026-09-23。适用于 City Agent 的人口背景层，不承诺把公开总量变成真实居民、实时位置或真实消费偏好。统计可信、软件运行成功和商业决策有效是三个不同的验收对象。

## 1. 先定问题，再定人口

每次录入冻结一张任务卡：区域名称、内部标识或已验证区划代码、边界版本、统计时点、常住/户籍等人口口径、研究人群、决策粒度、允许输出、停止条件。发布日期、统计时点、采集日分别记录。

街道总量只能回答街道层级问题。没有几何边界与空间约束，就不画貌似精确的热力图；没有单岁年龄/在校状态，不能从5–14岁或“受教育程度为小学”数出小学生。常住人口、家庭户、宠物只数、购买人数、订单量各有分母，不得互换。

本次已验证滨江三个街道名称；`binjiang/xixing/changhe/puyan` 是内部稳定 ID，不冒充已核验的官方区划代码。接入另一区域时不要复制滨江的人口数、行政映射或年份。

## 2. 搜索顺序与证据准入

1. 区域统计部门普查公报、原始统计年鉴和公开表格。
2. 年度统计公报及抽样调查，优先补总量与已公布结构；不自动覆盖旧普查结构。
3. 教育、民政等部门按明确分母发布的专题统计，作为独立维度，不随意跨表连接。
4. 官方媒体转载只用于找回发布链、核对转录，不算第二次独立统计。
5. 搜索摘要、百科、商业报告、POI与第三方地图是线索或另行审核的数据产品，不自动成为人口事实。

搜索日志必须记录查询词、访问失败、候选资料、采纳/拒绝理由和仍未找到的表。一次搜索没命中不等于资料不存在。本次2025政府页面曾访问失败，通过浏览器 User-Agent 获得原始附件；最终仍保留转载及访问过程。

滨江示范：2020七普提供全龄三街道人口、年龄、性别边际；2023—2025提供较新的区级常住总量。2023街道表是户籍口径，不能更新常住分布。2024公报男女是户籍、2025男女是常住，不能计算跨口径同比。详见 基线核验（源码相对路径：`BINJIANG-EVIDENCE.md`；需源码包） 和 近期核验（源码相对路径：`BINJIANG-RECENT.md`；需源码包）。

## 3. 原件留存和逐格转录

每份证据保留：统计生产者、实际发布者、标题、官方发布页、附件URL、发布日期、统计期、采集日、本地原件路径、字节数、SHA-256、单位和分母、页/表/行/列、脚注及访问条件。网页与附件各自留存；同一PDF的两个表索引不是两份独立资料。

PDF流程为下载原件 → 文本提取 → 关键页面渲染 → 对照图像核验表头、数字、脚注 → 行列汇总复查。文本提取结果不能替代视觉核验，尤其注意跨行表头和单位。保存的关键页图像位于 `data/population/evidence/`。

哈希只能证明所保存字节与登记版本一致，不能证明发布者身份、摘录正确或统计调查无偏。作者和网址核验、表格核对、算术检查分别保留；不合成一个没有解释的“可信度98分”。

人数优先保留原始单位和精度：2025年末55.9万人是1%人口抽样调查推算并按0.1万人发布，换算559000人不赋予逐人精度。当前通用编译器接受完整整数人数边际；舍入到万人的近期观测保存在独立 evidence JSON，不强制填进精确普查包。

未公开/未采集保持缺失，不填0；公开的0才录0。互斥年龄组才能相加，65+嵌在60+中不能重复加。教育表3+、户表“户”、家庭户人口“人”等各自保留分母。

## 4. 数据包录入与硬校验

使用 `data/population/regions/new-region-template.json`；模板有结构但没有观测和来源，预检被阻止是正确行为。数据包当前只表示一个统计时点、一个人口口径、一组互斥子区域，范围由 `regionPackSchema` 定义。

| 字段 | 要求 |
| --- | --- |
| region / period / populationBasis | 区域边界版本、统计期、人口口径，与每条事实一致 |
| areas / ageBands / sexCategories | 子区域、全龄连续互斥年龄组、原表性别分类，不凭空创造缺失分类 |
| sources | 来源与原件指纹；文件相对工作区存储 |
| observations | 区域及子区域总量、每个子区域完整年龄与性别边际；每格有原表定位 |
| derivation | 可选确定性减法，明确两个输入观测ID；输入链必须同区域、同口径，数值可复算，不得循环 |
| method | `independence` 或 `observed`；明确调研年龄组及方法说明 |
| limitations | 未知项、口径限制、发布误差与禁用结论 |

审计阻止：重复ID/单元、缺引用、年龄缺口/重叠、混年份/边界/口径、缺总量、缺边际、行列不等、联合频数不一致、派生链错误。声明 `observed` 时联合表必须完整；不能有表却丢掉它再假设独立。历史表的修约差异保留在证据层，不为了让审计通过而机械改原数。

本地执行（不下载文件、不自动覆盖现用城市）：

```bash
npm run population -- validate data/population/regions/binjiang-2020.json
npm run population -- compile data/population/regions/binjiang-2020.json --output data/population/binjiang-model-review.json
npm run population -- validate data/population/regions/new-region-template.json
```

第三条应退出1并报告缺证据/总量/边际。第二条输出必须是不存在的新文件；拒绝覆盖已有产物。网页“城市与样本”提供模板下载、JSON预检、当前数据包和模型导出；预检不激活上传数据。网页原件仅允许 `data/population/sources/` 专用目录，CLI允许工作区内原件，均检查真实路径和SHA-256。

适配新区域的交付物是“新包+原件+核验记录+编译报告”；完成预检后通过评审选择应用的数据包。**当前网页没有城市切换/数据包自动发布功能**，也没有自动爬取任意新区域的承诺。

## 5. 联合分布：什么已知，什么不可识别

现有滨江资料提供街道×年龄和街道×性别，没有本次已核验的街道×年龄×性别完整联合表。Demo使用：

`某街道某年龄某性别逻辑人口 = 同街道该年龄人口 × 同街道该性别全龄人口 ÷ 同街道全龄人口`

这相当于街道内部年龄与性别独立。结果标记 `infer`，保留三条输入证据和方法，不称作真实个体。可以为小数，因为它是逻辑频数/权重，不是半个人。全龄模型共24单元；筛选15+后12层用于通用流程夹具。先全龄编译再筛选，不把未成年人称为成年人。

给定年龄边际A、性别边际S、区域总量N，单个联合单元只能限制在 `max(0,A+S-N)` 到 `min(A,S)`，即 Fréchet 可行界。它不是置信区间，不能将每格上下界同时任意组合。即使每条边际误差为0，也不能证明年龄与性别的相关性正确。

若以后取得更多交叉约束，可评估IPF等方法；它们是后续能力，本版不声称实现。人口合成研究讨论了无个体样本时结合边际和部分联合信息的建模，但拟合约束本身不等于还原真实联合结构。[原始研究：Population Synthesis Based on Joint Distribution Inference Without Disaggregate Samples](https://www.jasss.org/20/4/16.html)。

## 6. 抽样、消费行为与决策停止线

通用Demo用固定seed生成30–600个逻辑代表，每个非空层至少1个，其余按最大余数法分配，权重为层人口/样本数。每次保存数据包hash、原件hash、规则版本、seed、输入与分层权重。权重回归总体是算法保证；增加合成样本不能修复缺失的人群属性或消除人口模型偏差。

人口来源真实 ≠ 合成人设真实 ≠ 商品偏好真实。当前兴趣、预算和作答均为未校准规则，商品标签不参与通用偏好模型；不生成真人总体置信区间、真实销量或利润。ONS同样强调合成数据不指向真实个体，不能预期保留全部真实特征，必须说明用途与限制。[ONS 合成数据政策](https://www.ons.gov.uk/aboutus/transparencyandgovernance/datastrategy/datapolicies/syntheticdatapolicy)。

两个专用case把数据适用性当作前置检查：小学生场景缺在校生/家长购买/候选门店与路径；宠物场景缺养宠结构/猫狗/自有匿名订单/网点用途/同规格价格。本版可以交付 `needs-data` 的条件研究方案，不能给无证据的滨江具体地址或主营比例。两例验收矩阵（源码相对路径：`SCENARIO-READINESS.md`；需源码包）。

真实补采优先使用公开聚合数据和用户合法持有的去标识汇总。涉及儿童时先明确监护人参与、学校协调和伦理审查，不收集个人住址、轨迹或直接向儿童进行无监护调查。这里是研究设计边界，不代替合规审查。高精度个人位置不是“追溯”的必要条件。

## 7. 发布与后续更新

采用三层闸门：

- 数据可建模：结构和口径通过、原件字节校验通过、人工转录核验已记录。
- 软件可交付：真实浏览器断言通过、artifact与数据版本可回查。
- 研究可决策：目标人群/空间/行为/成本等关键证据满足；真实补采及外部验证未做则保持needs-data。

新年份不覆盖旧包，创建新版本并记录变动来源；边界变动须独立crosswalk，不能默认为同一街道。近期总量与历史结构分层展示；如果明确做比例外推，必须另存推估情景和稳定结构假设，本版未实施该外推。

每次运行冻结 `datasetHash`、来源hash与执行清单；历史任务结果继续指向原版本。数据公开分享时同时带原件链、核验记录、未知项和版本，不只发送漂亮地图或生成居民头像。对外演示路径见 三分钟讲解稿（源码相对路径：`DEMO-TALK-TRACK.md`；需源码包）。
