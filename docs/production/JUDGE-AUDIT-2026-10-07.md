## 必须保留的负结果与分母

三条 MOCK-01/02/03 是用户授权自拟的同一待办应用场景：工程行为 Gate 3/3，生成模型请求 0。不能称三条真实业务需求、三个独立产品或真实自主交付率 100%。六次申报基线真实四角色失败属另一冻结阶段，不覆盖、不挪作本线成功。

历史 Jev：v1 首次请求协议不一致失败，其后两项 skipped；v2 另开配置，首候选 1/3、选优覆盖 2/3、全部题目选优后 Gate 2/3、有选择时 2/2。另一次混合运行在产品阶段 uncertain 后停止，尚未进入研发/最终 Gate。全部五次真实请求均纳入总费用：输入 15027 / 输出 874 Token，声明单价估算 **0.000631134 USD**，不是账单；外层开发、设备和录屏成本未计。未作全局最优答案、普遍可靠性或实际节省成本结论。

LLM-as-a-Verifier 是结构化候选评审与预算化升级，不是只要求模型返回“通过”。Jev 快速层接受后仍必须通过独立硬 Gate；不确定时可以升级一次 LLM Verifier，错误/预算不足/未知 usage 时 fail-closed。Jev 分数与集中度不是校准准确率；一个候选的多个评分不是独立重复实验。AnyJev SDK 是待办，不把托管 TypeSafe Jev 的接入写成已经实现完整 AnyJev。
