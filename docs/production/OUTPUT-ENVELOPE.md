# Grouped v4 输出导航与完整 JSON 自检

日期：2026-10-09；基线：`929635d1c805e7a9abe5fdb7d30b7dd41291a991`。只在独立生产分支实施；不改 HTML07 原文或已提交申报。

## 依据与目标

HTML07 启动守卫已通过，但研究两次语法错误耗尽返修，普通 PM 又输出额外 `risksNote`。全部响应具有 wire-observed JSON-object 请求证据，仍不能保证合法 JSON 或严格 Schema。这是通用输出可靠性问题，不据此降低原八条业务或增加题目专用分支。

新 `production-html-grouped-v4` 仅用于显式 `planned-groups-v1`。研究员和项目经理收到顶层 `outputEnvelope`，从本阶段实际 `outputContract` 的闭集 Schema 派生根 allowed/required 字段与字符串/对象数组的字段路径；包括任务项与验收计划嵌套项。绑定 role、phase、完整原序契约 SHA-256，所有结果深冻结。不复制 enum/default/description、业务答案、源 quote 或候选。

完整 JSON 自检仅在模型内部：逐项字符串引号及转义、全部 required 字段后再闭合根、不加空 note/metadata/自检总结。鼓励短句去重，但不得省略需求、事实、约束或 unknowns。这是提示指导，不是供应商 constrained decoding、宿主解析修补或通过证书；改善模型正确率、返修率及费用尚需新冻结实测。

## 不变与安全边界

- 完整实际 Schema、严格解析/未知字段拒绝、独立 Verifier、原冻结 Gate 保持。两个研究错误和 PM 额外字段原文作为只读回放，仍拒绝，原始输出不编辑。
- 不新增调用、不设置局部额外纠错；最多两次全局共享返修，unknown/取消/传输或协议致命失败不能借本功能续跑。产品、测试、研发、Verifier 不增加导航。普通 HTML 与 camera 路径、旧 grouped v1/v2/v3 导出字节保留。
- 导航树只接收宿主普通 JSON，拒绝 Proxy/accessor/toJSON/循环/非 JSON/开放对象/引用/union/tuple 等不支持构造。边界为 32KiB 完整 wrapper、10,000 节点、深度16、每对象64字段。既有实际 Schema 导出的32,000字节限制和提示60,000字节限制不提高。
- Zod 实际导出根 `jsonSchema` 有非枚举数据属性 `~standard`；仅该精准位置允许忽略，不访问其值。getter、其它隐藏属性、嵌套同名属性仍拒绝。完整 JSON.stringify 的 Schema 字节和哈希不变。
- 新版本/字段/固定错误在 Agent/Jev 设置中受保护；全部历史加密凭据仍参与碰撞拒绝。免费预检和启动使用同一完整固定导航、完整角色指令集合，不截断、不丢历史。100k 窗口、100k 加密、1M 前缀限制不扩大。
- 新 v4 的 PM 提示仅对已有 PM 输出说明做等义去重，保留阶段/合法默认值/诊断绑定规则；不是修改旧 v3、冻结业务或 Schema。新增通用自检先行精简仍不足以通过六种凭据长度的扫描，因此用完整新提示去重而非截断检查。
- study 的固定 selected set 更新为 source-v8/54（新增实际依赖模块）；不是完整递归依赖图、已加载运行时证明或旧实验重新认证。旧原件和 source-v7 仍留存。

## 步骤容量反例（工程夹具，不是交付）

每负例“填金额、提交、提示/数量/总额/小计各断言”是6步，5种金额单状态30步。独立 setup、每次其它合法字段重填与内容不变断言后，示例空态49、已有态53步：均超过原20，PM文字14/20不能放行。拆为10个独立槽位后，每项空态13/已有态17，可在总12与单项20内结构通过；这仅证明该布局容量合法，不证明八条完整覆盖或所有布局可行/不可行。

实际17仍超过计划14须拒绝；总13项与单项21步仍拒绝且不裁剪。`assertChanged.after`沿用原门禁一个外层数组条目，不误算为两个。弱语义布局可以通过容量/结构，反证计数和审计不能认证有效 setup、业务意义或最终执行。
