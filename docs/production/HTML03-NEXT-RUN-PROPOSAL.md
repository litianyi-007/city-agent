## 建议只跑一个最小真实闭环

需求原话：

> 为小团队做一个无需登录、无需网络的单页费用记录页：填写描述、金额并选择“办公/差旅”后添加记录，支持删除及“全部/办公/差旅”筛选，准确显示全部费用总额和当前筛选小计；金额只接受0.01至9999.99元（含边界）、最多两位小数，无效金额或空白描述应提示且不得入账，数据仅在当前页面保存。

这是用户授权范围内自拟的演示题，`kind=illustrative`，没有实际需求方或工单；拟用真实模型而非 Mock 响应完成。采用 `live / offline-single-html / llm-rubric / legacy / 1候选`。不传 demoCaseId、摄像头配置、现成 HTML、已有模型产物或外层固定 checks，费用页不走已有待办夹具回退。

验收重点：初态零条与 `0.00`；`10.10` 办公加 `20.20` 差旅后2条、总额 `30.30`；分类筛选只影响显示和小计、不改全部总额；`0.10+0.20` 精确为 `0.30`；`0.01` 与 `9999.99` 两个含边界有效值合计 `10000.00`；负数、零、空金额、三位小数、超上界及纯空格描述均拒绝且已有状态不变；筛选中删除不丢其它记录，删除最后一条归零。完整业务验收以预登记八项为准，不能在运行中删改成较易通过的版本。

测试角色自主生成合法普通 CSS 与精确行为 checks，评审及结构/语义预检后、研发前冻结完整 checks/hash。每项独立 setup，条目数量、内容、状态和金额分别核对；精确文本不选包含操作按钮的整行。业务使用明确 click，不依赖被现有 CSP 禁止的原生 form.submit，不要求现 Gate 不支持的 reload/键盘/selectOption。没有把外层验收数据写成模型已完成的产物。

## 配置与预算建议

计划沿用本分支六角色现有页面配置 `DeepSeek / deepseek-flash / https://api.deepseek.com`，输入/输出 `0.30/1.20 USD` 每百万 Token 的声明价。最终准备时只核对脱敏 public 配置（角色、ID、模型、enabled、hasApiKey、单价与币种）；本提案不假装已经读取或核验实际快照。价格不是供应商发票，不迁移 Key、不以文档代替已有控制面凭据。

建议单次停止额度 **1 USD、24调用槽位、500000总Token、每次6000输出Token、600秒、最多2次共享修复**。正常为6次阶段选择，各1候选+1 Verifier，12逻辑 Harness 调用意图；仅两次 Gate 返修时20；最坏两次研发前产品/研究/规划重做时24。实际供应商 HTTP 另外观测计数，不能把逻辑槽位称为已发生POST。

估算公式为 `(输入Token × 0.30 + 输出Token × 1.20) / 1000000`；规划预测 `0.03–0.25 USD`，不作为已花费、账单承诺或完成保证。安全预留、上下文容量、总Token与时间可能早于24槽位耗尽。全部候选、拒绝与自动修复计费记录保留；unknown usage/费用停止，不记零、不自动追加额度或新运行。旧 unknown 不追改，本次1 USD授权不追加新运行；外层建设/机器/人工费用未统计。

## 为什么首轮不同时做 A/B

[HTML-01](experiments/HTML-01/RESULT.md)的静态评审漏掉表单/DOM契约问题，硬 Gate 保留失败；[HTML-02](experiments/HTML-02/RESULT.md)在研究 JSON 阶段耗尽两次共享纠错，没到研发。先用当前严格 JSON与阶段评审、已公开执行事实跑一次真实 HTML 闭环，更便于归因；不手改 JSON、Gate 或模型代码。

source-bound-v1 的免费工程验证不等于真实模型效果验证：它不增加 Verifier 调用槽位，但会增加源码引用、证据 JSON 和 Token，并引入缺失/引用不符的失败关闭风险。Jev v4 与 source-bound 对照都留待之后独立预登记和预算授权，不作为本次隐式 fallback 或第二次付费尝试。不同完整运行生成的检查/候选不相同，不能据此直接归因质量或费用差异给证据政策；正式匹配对照要另行固定输入、候选、验收与统计口径。

本次不打包实机摄像头、外网、任意仓库执行、正式业务工单、泛化或稳定性目标；不因一次 completed 宣称六角色普遍可靠、选优节费、完整恶意代码安全或正式 L4/L5。生成 HTML 仍只下载文本与受控截图，不在用户浏览器执行。现有主稿、历史实验、录屏和血缘保持原样。
