## 输入快照（不可在结果出来后改写）

原话：开发一个梦幻的圣诞树，能通过摄像头获取手势，来控制圣诞树。

用户确认：张掌散开、握拳聚合、掌心横向位置旋转；允许受控摄像头能力扩展。背景：检验本地服务从一句话到受限产品的内部自主交付质量。来源：用户本会话提出的测试请求，无业务工单/商业效果证据。

验收：夜色中可见梦幻粒子圣诞树、星形顶饰与雪；摄像头默认关闭，点击开始才请求视频，关闭释放；三种手势按确认映射作用于实际几何；无手/权限拒绝/设备或模型不可用有清晰状态；按钮/键盘可回退但不计摄像头通过。不保存/上传帧，不接触模型 Key。平台合成 Gate 与真实视觉/实体设备验收分列。

- 能力：camera-scene-v1；现有 DeepSeek Harness 0.1.5-rc.3，不升级。
- 六角色：用户在本分支已设置 Key；只检查 hasApiKey，不记录 Key。默认旧 ID 退役后，用户在实验前明确选择 DeepSeek / deepseek-flash；不静默替换。
- 单价：用户明确采用高峰非缓存输入/输出 0.30 / 1.20 USD 每百万 Token 的保守估算，已通过本地受控 API 更新六角色非秘密元数据，原 Key 保留。低峰/缓存可能更低，账本不是实际账单。
- 候选：每环节1个，均通过 Verifier；Jev cascade 快速类型化审查，不确定时 LLM rubric 复核，不以 Jev 接受替代行为 Gate。
- 本轮最多1个启动尝试；如果工程缺陷导致失败，修复平台后登记新配置/新 Run，不覆盖旧 Run。
