## 对抗审查与修复

外层开发 Agent 建设平台，与平台内部真实角色调用分开。独立审查覆盖 code-quality/security 及非作者 server 接线；辅助模块作者不审自己的模块作为独立证据。

1. P2：初版源检查错误要求 generation.error 已存在，阻断结构合法但被 Verifier 弃权的 PM 再生成。修为核对真实 Oracle 原响应与持久化同候选弃权；补首轮弃权后新生成、连续三轮弃权耗尽两修复的夹具反例。没有伪造生成 error、放宽评分或退款预算。
2. P2：新增取消测试进入 PM 的等待缺少上界，前置失败可能挂住测试。补10秒有界进入等待，finally 清理 timer 并释放 barrier；不是增大产品超时。

最终三路复核均无开放P1/P2。非作者code-quality独立pure12/12；security独立五文件95/95后单独补删除诊断1/1；辅助模块作者仅审查非本人server接线，4/4质量弃权/预检专项通过。以上互相重叠，不与933或106相加。另统一任务文档为六角色生产链，避免混同冻结四角色Demo。模型效果、真实完整分组Gate及成本改善仍由下一次独立实测决定。
