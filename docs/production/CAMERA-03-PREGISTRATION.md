- acceptance `production-camera-acceptance-v1`、mandatory Gate `camera-scene-behavior-v1` 不变；可信运行时及资产 pin 不变。启动源码 commit、运行时 hash、配置 hash 和干净构建时间从本次真实记录归档，未冻结提交之前不调用模型。
