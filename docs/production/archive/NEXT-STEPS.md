## 架构与协作限制

优先保持 DeepSeek Harness 及受控执行器的最小方案。只有复现关键不适配后才评估第二运行时，变更前需用户选择；本轮不升级 SDK、不引入其他运行时。

虚拟社会的人口、人群、调查、现实桥和记忆属于另一研发线。不直接编辑另一 worktree。确有共享接口需求时，以版本化、向后兼容的小改动单独提交，供另一线审查后 cherry-pick，不自动合并。

不把多模型协作意见当实际验证。Hopper/grok-4.7 为可选评审工具，当前未探测或调用；后续调用前核对真实支持、模型 ID 和预算，不静默替换型号。
