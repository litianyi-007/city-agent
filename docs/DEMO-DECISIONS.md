# Demo 决策与对抗性审视（2026-09-23）

本次用户指示覆盖旧 Phase-1 排期。原文完整保存在 [archive/2026-09-23-before-demo](archive/2026-09-23-before-demo/)，对应 Git 基线 `111027d`。这里先冻结实施边界，交付状态见 ROADMAP。

## 必须纠正的方向

| 旧方案的问题 | 建设性调整 | 代价与验收 |
| --- | --- | --- |
| L5 是第二条轨道，排在人口底座与外部评审之后 | L5 是主产品；城市商品调研是首个用户任务 | 暂不交付完整社会仿真；先证明一次任务能产出程序并通过实际测试 |
| 研发人群包只能读，角色不能执行 | Agent 是执行角色；Persona 是统计模拟对象，分开建模 | 四个 Agent 各有角色与模型配置，居民不常驻 |
| 等全部口径确认再写代码 | 使用可核验历史人口表，缺失联合分布显式标推断 | 人口评审继续改善有效性，但不再阻塞工程闭环 |
| 一次大而全的自主开发难验收 | 首版限定为离线单页 HTML/CSS/JS 应用 | 无任意 shell、部署、第三方账号操作；复杂后端需求应报告超出范围 |
| “四个角色都说完成”不等于 L5 | 测试在实现之前冻结，程序化浏览器 Gate 独立判定，最多两次返修 | 保留退出结果、断言和产物；失败不能人为改为通过 |
| 没有密钥就做假实时推理 | 明示“流程演示”和“真实模型”两种模式 | 演示验证编排与 UI，不能作为真实 L5 成功证据 |
| 模拟人群规模大容易掩盖效度不足 | 报告总体、调研框、样本量、权重、来源与模型限制 | 无真人对照前，只支持预演和假设生成 |

## 当前裁决

1. **优先 DeepSeek Harness。** 官方 TypeScript SDK 提供可编程会话；通过单独适配器接入。固定 npm 版本，禁用与有界生成无关的主机工具。模型可以逐 Agent 配置。
2. **第二选择为 OpenHands SDK。** 仅当 dsh 在安装、模型路由或可控执行上出现已验证的不可解阻碍，才替换唯一执行器；不并行维护两套。旧 ADR-004 的优先级由此覆盖。[dsh 官方源码](https://github.com/deepseek-ai/deepseek-harness) / [OpenHands SDK 官方源码](https://github.com/OpenHands/software-agent-sdk)。
3. **模型配置是运行快照。** 复制 Agent 复制其配置；每次运行选择每个角色各一名。配置修改不改变正在运行的任务；Key 仅在本机服务端加密保存，不回传浏览器。
4. **无人干预是运行属性。** 用户提交一次任务之后，计划、研究、测试设计、实现、验收和有限返修自动完成。失败、取消、超时和重启中断都如实记账。
5. **商品调研分两层。** 系统内置的确定性人口抽样与意愿公式是透明示例数据工具；真实运行由四角色使用该上下文研发一个应用。它不证明 LLM 已代表真实居民，也不证明商品市场效果。
6. **本机优先。** Node 服务承担模型连接、密钥、持久化与执行。前端是同仓库工作台；不将能管理 API Key 的开发服务部署到公网。

## 仍需后续验证的问题

- 用用户实际模型完成一次无人干预运行，衡量成功率、耗时、Token 与修复次数。
- 测试 Agent 可能遗漏需求，所以 Gate 通过只代表冻结的有限断言通过，不能宣传通用 L5。
- 2020 七普不是 2026 人口现状；数据更新和跨期口径不能省略。
- 年龄与性别的联合分布、收入和偏好不能由边际表直接推成事实。
- 若要扩展为任意仓库开发，先引入容器隔离、依赖安装策略和更强的验收沙箱，再开放 shell。
