2. 页面附件名为“2020年度《统计年鉴》（外版）1130.pdf”。HTML 附件路径与[政府云存储原件](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2945/site/attach/0/87ab83d95bd24748b0747c7ab72bf6ce.pdf)共享同一文件名 `87ab83d95bd24748b0747c7ab72bf6ce.pdf`。

4. 本地已保存未经改写的 [PDF 原件](../../data/population/sources/binjiang-census-yearbook.pdf)和[发布页 HTML 快照](../../data/population/sources/binjiang-census-yearbook-landing.html)。PDF 共 140 页、2,048,236 字节，SHA256 为 `70119b88dc3209909f237921ae9efc764c5011d7e6f6032d1d27c2a1949fb966`。HTML 快照为 15,092 字节，SHA256 为 `3c3635fcdbe199fb1c8e6c5311949cc28d5f84d03f18d5ca4736e568d7564ab1`。

搜索结果中出现了使用政府页面标题、但域名为赌博或营销站点的镜像。本证据仅接受政府原站及其相同附件；搜索摘要和镜像均不作为数据来源。哈希用于检查本次文件是否变化，本身不是官方签名或数据准确性的证明。

## 家庭与教育：可加入约束，但分母必须正确

| 表 | 印刷页 / PDF 页 | 已录入内容 | 使用限制 |
| --- | --- | --- | --- |
| 1-3 家庭户状况 | 110 / 118 | 三街道家庭户户数、人口、女性、平均户规模 | 家庭户人口仅 395,911，不能代表全部 503,859 常住人口 |
| 1-7 受教育程度 | 114 / 122 | 三街道八类受教育程度人数 | 只统计 3 岁及以上，共 489,131 人；不是全龄分母 |
| 同册七普公报 | 131-132 / 139-140 | 集体户、人口定义、教育定义和初步汇总脚注 | 公报数据自注为初步汇总数 |

全区家庭户 **165,654 户、395,911 人**；集体户 **33,005 户、107,948 人**。三街道家庭户依次为：西兴 55,791 户 / 123,394 人，长河 55,428 户 / 140,395 人，浦沿 54,435 户 / 132,122 人。原表表角统一印“单位：人”，但“户数”列须按户使用，“平均户规模”须按人/户使用。只有均值，无法恢复 1 人户、2 人户或亲属结构。

全区大学专科 91,920 人、本科 137,064 人、研究生 33,601 人，合计大学文化程度 262,585 人。原文“受教育程度”包含毕业生、肄业生和在校生，不能改称“已获得相应学历的人数”。按 3 岁以上教育构成展示时分母为 489,131；复现公报“每 10 万常住人口中拥有大学文化程度”的指标时分母为 503,859。两个指标都能算，但必须写清分母。

## 联合分布与原始 Demo 审计

此次检查了七人普章节目录、表 1-1 至 1-8 和同册公报，没有找到 **街道 × 年龄 × 性别** 的直接联合表。表 1-6 实际为民族，表 1-4 为户口登记状况，表 1-8 为来自区外 / 市外 / 省外人口；后者为嵌套范围，不能将三列相加。这个结论只限此次检查的资料，不声称所有官方资料都不存在联合表。

原始 `server/city.ts` 中的总人口、三街道人口、女性和四年龄组 **没有发现数值抄录错误**。不足在来源链只给 PDF 链接与表号，缺少年鉴年份、政府发布页、发布时间、原件留存及哈希。它将年龄与性别在每个街道内按独立性组合，并已标注推断；本次核验没有把这一假设升级为事实。

可信人口基线的证据，只覆盖上述时间、地域、口径和边际。没有社区、楼栋、网格边界或住户微观记录；没有真实居民预算、消费偏好或购买行为数据。人口约束一致，不能据此推导商品购买意愿已经可信。

## 可复核操作与通过项

```sh
shasum -a 256 data/population/sources/binjiang-census-yearbook.pdf
pdfinfo data/population/sources/binjiang-census-yearbook.pdf
pdftotext -layout -f 117 -l 122 data/population/sources/binjiang-census-yearbook.pdf -
pdftoppm -f 117 -l 117 -scale-to 1600 -png data/population/sources/binjiang-census-yearbook.pdf /tmp/binjiang-population
```

执行算术核验：三街道人口 / 女性与全区一致；年龄四组按街道与全区双向相加一致；家庭户户数、人口和女性汇总一致；教育每行类别、每列街道汇总一致；家庭户与集体户人口合计等于常住人口；专科、本科和研究生合计等于公报大学文化程度人数。数值对齐是必要校验，无法证明年龄性别联合假设或合成消费回答真实。
