# 产品说明：L5 优先 Demo

状态：本地 demo 已实现。本文按 2026-09-23 用户最新指示更新；[原始 Phase-1 文档](archive/2026-09-23-before-demo/PRODUCT.md)完整保留。设计取舍见 [DEMO-DECISIONS.md](DEMO-DECISIONS.md)。

## 1. 核心目标

用户在页面输入一次任务，产品、研究员、研发、测试四个执行 Agent 自动完成拆解、研究、代码产出、独立验收和有限返修，交付能打开使用的小型应用。运行中途不需要人工确认；用户可以主动取消。

L5 在当前阶段是**有界自主研发目标**：仅支持单文件离线 HTML/CSS/JavaScript 应用，验收以预先冻结的声明式浏览器断言为准。不得将流程跑通或固定演示模板说成“通用 L5 已实现”。

## 2. Demo 范围

| 能力 | 实现约定 |
| --- | --- |
| 角色 | 产品、研发、测试、研究员；每个 Agent 具有一个角色，可修改 |
| 模型 | 每个 Agent 独立 provider / base URL / model ID / API Key |
| 团队管理 | 新增、编辑、复制、启停、删除；可创建同角色多个候选 |
| 一次运行 | 每个角色选一名，共四名；配置与凭证快照冻结 |
| 自动拆解 | 产品生成目标、分角色任务、交付物、验收标准与限制 |
| 研究 | 使用登记的人口上下文，返回带来源类别的结论与风险 |
| 测试 | 在研发之前产生浏览器交互断言，随后独立执行 |
| 研发 | 生成真实 HTML/CSS/JS；自动修复 Gate 失败，最多两次 |
| 展示 | 实时阶段与日志、历史任务、角色原始输出、Gate、产物预览及下载 |
| 留痕 | SQLite 运行记录、输入与模型快照、产物哈希、Token、耗时、返修次数 |

当前 SDK 不支持 temperature，明确不纳入配置。模型连接协议支持 OpenAI 兼容 Chat Completions 和原生 Anthropic Messages。底层采用 DeepSeek Harness，不另造同名模型调用壳。

## 3. 首个任务：滨江商品调研应用

默认需求：为西兴、长河、浦沿的模拟人群开发 AI 生活服务会员调研页面，展示人口结构与模拟接受度，支持调整价格与街道比较，能解释来源和适用边界。

公开统计锚点为滨江官方年鉴中的 2020 七普三街道人口、性别、年龄边际：全龄人口 503,859，15 岁及以上调研框 434,827。旧“约 30 万”为命题规划参考，不再作为真实总体数量。

数据层遵守：

- `fact`：有引用的公开人口边际。
- `infer`：街道内年龄与性别独立假设下的联合层、合成样本属性。
- `generated`：兴趣、预算、规则意愿、合成回答。

30–600 个代表样本，不为每个居民常驻一个 Agent。每次记录 seed、分层、权重、来源与规则版本。0–14 岁不作答；15–59 岁原表包含 15–17 岁，不能称成年人口调查。

**效度限制：** 当前是规则仿真数据工具，所有人口组采用相同偏好分布，商品文本只作为标签。价格升高导致意愿下降由公式保证，不能作为真实价格弹性的验证。这里的研究 Agent 使用数据研发应用，不等于居民 Agent 已完成商品访谈。

## 4. 两种运行必须区分

| 模式 | 模型调用 | 代码来源 | 可以证明什么 |
| --- | --- | --- | --- |
| 流程演示 | 无 | 版本化模板 | 配置、编排、产物、真实浏览器 Gate、记录可使用 |
| 真实模型 | 四角色各自配置的服务 | 研发角色的实际模型回复 | 这次有界任务在冻结断言下是否自主完成 |

集成测试中的本地模型替身只能验证软件协议、状态转换和返修，不能代替真实供应商模型的质量证据。真实运行失败时不得自动回落到演示模板并显示成功。

## 5. 验收标准

1. 用户能从页面配置和复制 Agent，并为四个角色选择不同模型。
2. 一次提交自动生成规格、研究、验收条件和页面；没有中途人工补提交。
3. 测试条件在研发前冻结，至少包含可观察的交互效果；浏览器独立判定。
4. 错误真实显示，最多两次返修，单角色 180 秒、整次 15 分钟、模型调用最多 12 次；取消能终止子进程和浏览器。
5. 输入、配置快照、运行状态、Gate 与交付物可追溯；重启把未完成记录标为中断，不伪装恢复成功。
6. 模拟与真人、事实与推断、模板与模型生成在页面与产物中清楚区分。

## 6. 当前不做

任意仓库开发、后端服务生成、生产部署、网络工具自治、持续社会运行时、居民长期记忆、图数据库、上链、MMO、真实市场效果承诺。原计划的双基线、LLM 居民作答、三类完整社会效度评测仍待后续实现；不计为本次 demo 已完成能力。

统计评审从实现前阻塞项改为后续质量改进项。真正需要市场有效性时，应补齐真实商品语义、业务量纲、人口口径、偏好校准与真人对照。
