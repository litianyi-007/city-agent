## 1. 交付目标与边界

用户创建或导入问卷，选择总体和多维人群，获得适用性与证据缺口检查；通过条件满足的任务后，由宿主执行居民模拟作答和确定性分析，再由产品、研究员、研发、测试四角色自动交付并验证离线分析页面。研究任务的通用性来自版本化契约与执行器，不来自增加场景关键词或模板分支。

- **L5 优先**：真实四角色单页交付链可以先接固定回答夹具验证，不等待完整人口数据平台。最终仿真闭环必须接入实际居民模型回答，不能用固定夹具冒充。
- **命题必做**：至少一份完整问卷实际运行；人口结构、画像/回答自洽与重复性、群体/变量响应三类合理性验证。真人问卷和真实业务对照是增信项，不是合成 Demo 的启动条件。
- **工程范围**：四角色自主研发仍限离线 HTML/CSS/JavaScript 单页。居民执行器是宿主能力，不宣称现有四角色已自主开发或部署后端。
- **证据范围**：事实、推断、显式假设、模型生成分别标记；数据可追溯、仿真完成、页面交付、现实有效性分别报告。不得以网页 Gate 或多模型共识证明市场准确率。
- **通用范围**：固定 schema 内支持单选、多选（含最多/恰好选三项等约束）、量表、数值、开放回答；未来有界追问须另行实现。非法或未知 schema 字段、题型、跳题配置返回 HTTP 400 和字段错误；仅合法契约中明确声明但当前不支持的 `requestedOutputs` 返回 `unsupported`，不悄悄改写任务。

已实现接口为 `GET /api/research/templates`、`POST /api/research/validate`。校验只返回结果，不保存、不激活、不启动任务。预检 `status: ready | needs-data | unsupported` 中的 **`ready` 仅表示契约/人口框预检就绪**；本批返回 `executorAvailable: false`。新 schema 尚未接入旧 `/api/runs`，旧 UI 的关键词场景流程也未迁移，不能将旧流程完成当成新问卷执行完成。本轮没有新前端、没有 LLM 居民作答、没有真实供应商实验或付费调用。

本批仅校验语法/结构、登记框适用性及引用关系，不自动证明题意、数字单位与问题量纲、`decisionContext` 之间的语义一致；`semanticValidation: not-performed`。非空 `unit` 只保证提供了单位文本，不等于单位正确；上下文自报也不建立购买/使用资格。自然语言语义识别和跨题逻辑校验不扩大到本轮实现。源文件完整性前置检查失败时，HTTP 409 `blocked`，与合法任务预检的三种结果分开。

状态约定：`in-progress` 表示实施中；`pending` 表示计划中尚未完成；`blocked` 必须附具体缺口；`done` 必须附产物及 EV 运行证据。首批 5 个子任务完成，不意味着六个工作包均完成。

## 4. 里程碑与并行关系

1. **M0 契约基础（已交付）**：本轮首批切片。82 项自动化测试、4 项浏览器回归与构建通过；只有 schema、三配置、只读 API、证据语义，无居民或前端新能力。修改前原文件在 [留底目录](archive/2026-09-23-before-research-contract/README.md)，已核对 SHA-256。
   **M0.5 配置工作区（已交付）**：独立调查页、人群预设、草稿持久化与逐预设预检；本轮验证范围见 EV-25/26。修改前原文件在[本批留底](archive/2026-09-24-before-research-workspace/README.md)。
2. **M1 两线同时跑**：T2.2→T3.1 的 10 人居民冒烟，与 T5.2 的异构四角色夹具页面交付并行。真实服务就绪及用户授权后才执行实际调用；Hopper 登录不等于项目 API 凭据。
3. **M2 完整问卷闭环**：至少一份完整问卷真实作答→确定性分析→三类验证→四角色页面交付；附成本、失败和证据状态，不要求真人基线。
4. **M3 配置复用**：三套已知问卷与至少一个未见配置复用同一管线；另行开展现实校准和候选点经营验证，不与合成 Demo 混成一个通过状态。

所有实际运行需保存任务、总体/画像、问卷、提示、模型配置和统计版本，及用于验收的原始产物。外部模型授权、成本上限或新数据权限未就绪时，只完成本地夹具与契约验证，不自动使用其他账户或替换供应商。
