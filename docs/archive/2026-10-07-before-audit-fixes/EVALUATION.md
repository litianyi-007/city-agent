# 通用问卷仿真与有界 L5：验收协议

更新：2026-09-24。协议状态：M0 契约与 M0.5 配置/持久化已验证；目录条目是**总体验收要求，实际通过范围见第 4 节**。任务归属见 [TASKS.md](TASKS.md)，历史 Demo 的既有测试证据见 [VALIDATION.md](VALIDATION.md)。本批已实现新前端，但未做新 UI 浏览器交互验收，也没有真实供应商或居民作答；不得用已有回归或 Hopper 评审替代居民仿真完成证据。

## 1. 三层门限，禁止混淆

| 层次 | 能够说明什么 | 通过/报告方式 | 不能说明什么 |
| --- | --- | --- | --- |
| 工程硬门限 | 契约正确、隔离/预算有效、答卷可解析、统计可复算、页面能运行 | schema、安全、数值一致性等确定性断言必须通过；缺失能力必须拒绝 | 真人偏好、市场需求、经营收益或通用 L5 已证明 |
| 内部合理性诊断 | 人口结构约束、画像自洽、重复稳定、变量敏感性及相对基线的表现 | 必须运行并报告三类检查及负结果；诊断目标预登记，可显示未通过 | 拟合边际不等于恢复真实联合；稳定不等于有效；模型共识不等于真值 |
| 现实有效性 | 在指定人群/任务/时期，与独立真人或业务留出数据的符合程度 | 当前未验证；未来说明样本、误差、代表性和比较基线 | 未经对照不得从模拟选择率外推滨江需求、选址收益或猫狗市场份额 |

命题要求至少一份完整问卷及三类合理性验证；真人对照不是合成 Demo 的强制前置条件。有依据的失败诊断也是结果，但不能把“评测已运行”说成“模型通过所有检验”。

首批预检的 `ready` 仅表示契约/人口框预检就绪，不表示执行器可运行、仿真有效或现实结论可用。首批 `executorAvailable: false`；`needs-data` 指出具体缺口；只有合法契约中明确声明但当前不支持的 `requestedOutputs` 返回 `unsupported`。非法或未知 schema 字段、题型、跳题配置返回 HTTP 400 和字段错误；人口源文件完整性前置检查失败则为 HTTP 409 `blocked`。带显式假设的合法情景可作为后续模拟输入，不自动解除现实外推限制。

本批仅执行语法/结构与登记框检查，`semanticValidation: not-performed`；不自动确认题意、`decisionContext` 和量纲一致。例如支付金额题的 `unit` 非空只证明单位文本存在，不能证明它表达货币/时间而非其他维度。上述限制必须与 ready 一同展示，不能把语义校验或 NLP 能力计入本轮通过项。

## 3. 最小实验设计及解释规则

### 3.1 固定实验单元

实验前冻结任务/问卷、总体包、画像、分层/筛选、统计代码、提示模板、模型 selector、供应商、参数、预算和允许重试次数。区分人口抽样 seed 与供应商推理 seed；供应商不支持后者时明确记录，不承诺 token 级重放。

开发四角色与虚拟居民是两种任务执行者：前者负责拆解与产物交付，后者提供模拟答卷，账本及质量指标分别计算。一次模型请求可批处理多个画像，不能简单要求“调用数大于样本数”；仍需保证隔离语义、逐画像原始回答与失败可追溯。

### 3.2 答卷完整率是工程指标

工程完整率 = 有效完成其全部应答题目的画像数 / 该批预先计划纳入的画像数。首次失败后有限重试成功只计一个画像；拒答、格式错误、预算中止或超时不能从分母消失。跳题/不适用只有符合预先冻结规则时才不算缺答。

先跑 10 个画像检查路径与预算，再决定是否扩至约 30 个。30 人批次的 ≥95% 完整率目标意味着至少29份有效完整答卷，不表示29位真人、95%预测准确率或合格市场样本量。基准批禁用答卷缓存；常规运行如用缓存，须另列新推理/缓存贡献且不冒充真实新调用。

### 3.3 三类验证必须可失败

1. **结构层**：边际误差、分母守恒、筛选适用性、联合推断依赖；这是约束拟合与数据工程检查，不是消费行为校准。
2. **个体层**：逻辑约束、自洽、随机抽样追问（建议）及重复稳定；五次中四次结论一致是可调整诊断目标。不得靠缓存、过度修正答案或删除失败让指标通过。
3. **群体/实验层**：画像条件差异、价格/权益单变量试验、措辞/顺序稳健性、基线与属性消融。先少量条件估算成本，再决定扩大，避免默认全因子实验。

核心结论必须在重复前定义，例如首选品类、给定价位的模拟选择率排序或是否存在明显分组差异；不能事后挑选最稳定的一句话。量化差异应报告幅度而不只有方向。

注意消融对象：仅打乱完整画像的居民 ID 本来就不应改变总体分布；它可检查追溯映射，不能作为“画像无作用”的证据。检验画像作用可删除任务相关字段，或在保持可解释约束时改变字段与回答对应关系；有变化也不自动证明是真实人群效应。

### 3.4 误差与效度

模型重复、抽样或情景参数的变化区间必须标明来源；它们不是滨江真实市场比例的置信区间。重复调用同一模型不等于新增独立真人。任务问卷中所有假设权重、养宠率、照护资格、预算等均不能因输出数字精确而升级为观测事实。

外部校准将来使用合法去标识数据，并保留未用于画像构建、提示调优和阈值选择的真人/业务留出集；报告总体与分组误差、简单基线、时间及地区适用范围。该项当前为 `not-validated`，不是阻止有明确边界的合成 Demo 启动的理由。
