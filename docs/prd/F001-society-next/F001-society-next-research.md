## 原始负例复核，不重写结果

只读导入已存 `survey-run.json`，复算映射、答卷、统计与账本；原 manifest 的五份附件字节数及 SHA-256 全部匹配。原运行确为 `mode=fixture`、12/12 结构有效、16 题、0 模型调用/Token/API 费用。

两条材料中已披露的反例在原答卷中得到确认：

- `resident-005`：`price-range=none`（不考虑购买），`trial-budget=321.91` 元。
- `resident-009`：`price-range=none`，`trial-budget=183.21` 元。

预算题明示“不买填 0”。当前评分未登记此跨题约束，因此两份仍为 `status=valid`。这不是没有矛盾，而是评分器没有检查该语义。不得改 seed、删样本、改原值或将 12/12 包装成盲评通过。后续可以以新规则版本对同一原始答卷重评分，同时保留原评分。

## 新增回归与当前余项

审查发现导入 persona 的 truthiness 判断可能跳过显式非法值；根任务已改为 `persona !== undefined`。新增 `tests/persona-proof.test.ts` 回归在内存副本中同时把画像及预设设为 `null`、`false`、`0`、空字符串，并重算画像/Prompt 哈希；四种均由严格 schema 拒绝而不是靠指纹错误拒绝。原夹具仍可导入，专项 5/5 通过，无模型调用、无原输出改写。

以下缺口仍需在后续真实实验前处理，不能因工程测试通过而消失：

1. 本卷语义规则尚不覆盖采购资格、职业/家庭一致性、多选“未知/不考虑”与具体选项互斥、跨题条件预算；须先预登记新评分规则或独立盲评。
2. `risk-attitude` 是必答 1–5 量表，无独立“未知/不适用”值；因此“所有题都能保持未知”尚未成立。应逐题审查未知出口与资格跳转，不能把夹具自动填满当作未知行为验证。
3. 自定义描述、behaviorNotes 等自由文本可被用户预写偏好或刻板假设；结构 schema 与 Prompt 警示不会自动完成语义审查或提示注入防护。当前四份自证预设没有预写消费答案，不等于任意用户预设都满足此条件。
4. 新五层尚未做真实模型行为贡献、重测、措辞/题序、异构模型或真人/业务留出验证；既有真实 12×15 结果不能转移到新版本。真实 30 人 cohort 与授权预算仍待准备。
5. 2025 全区小学规模只缩小背景缺口；学校/校区与出入口、居住人群和家长分母、候选点成本/客流、当地宠物与零食消费证据仍不足，不可生成确定选址、主营比例或价格推荐。
6. 来源 URL 与哈希不完成自动人工核验、实时更新、五层事实绑定或数据包发布。现实桥 MCP、居民长期记忆、wiki/dream、有限自主接管均未实施。

本轮没有发现材料将上述未知项升级成已验证科学结论的致命矛盾。允许作为“可追溯画像配置与研究流程工程 Demo”交用户验收；不放行“真实居民偏好已验证”“现实绑定已实现”或“两个开店场景已形成可经营结论”的对外表述。正式发布与新增付费实验继续等待用户确认。
